description: New warning for potential EIN mismatches
---

The FAC has implemented a new warning to help users identify potentially incorrect EINs. When a workbook is uploaded, the FAC compares the auditee’s EIN with EINs from past submissions for the same UEI.

If the EIN does not match, the system will ask the user to double-check the number. Users can continue if the EIN is correct or update the EIN in their workbook before submitting.
